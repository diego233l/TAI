? ¿Qué componente de la plataforma Java incluye el compilador javac y las herramientas de desarrollo?
a) JRE
b) JVM
c) JIT
d) JDK
= d
> JDK = JRE + compilador y herramientas. El JRE incluye la JVM y las bibliotecas.
@ Java

? ¿Qué código genera el compilador javac?
a) Bytecode (.class) que ejecuta la JVM

c) CIL para el CLR
d) Código fuente intermedio en texto

> El bytecode es independiente de la plataforma.
@ Java

? ¿Qué organización se hizo cargo de Java EE y lo rebautizó como Jakarta EE?
a) Apache Software Foundation
b) Linux Foundation
c) Eclipse Foundation
d) W3C
= c
> Oracle cedió la tecnología a la Eclipse Foundation; Oracle conservó la marca «Java», por lo que el nombre cambió a Jakarta EE.
@ Jakarta EE

? ¿Qué cambio de espacio de nombres introdujo Jakarta EE 9 respecto a Java EE?
a) De java.* a jee.*
b) De javax.* a jakarta.*
c) De org.* a com.*
d) Ninguno
= b
> Jakarta EE 8 conserva javax.*; desde Jakarta EE 9 se usa jakarta.*.
@ Jakarta EE

@ Jakarta EE

? ¿Cuál es el ciclo de vida de un servlet?
a) start(), run() y stop()
b) open(), read() y close()
c) create(), update() y delete()
d) init(), service() (doGet/doPost) y destroy()
= d
> El contenedor crea una instancia, la inicializa una vez y atiende las peticiones con hilos hasta destruirla.
@ Servlets

? ¿Cuántas instancias de un servlet suele crear el contenedor y cómo atiende las peticiones concurrentes?

b) Una instancia por usuario

d) Una única instancia atendida por varios hilos
= d
> Por eso los atributos de instancia de un servlet no son seguros para hilos.
@ Servlets

? ¿Qué objeto permite mantener estado entre peticiones HTTP de un mismo usuario en un servlet?

c) RequestDispatcher
d) ServletContext únicamente
= a
> ServletContext es compartido por toda la aplicación; HttpSession es por usuario.
@ Servlets

? ¿En qué se transforma una página JSP en tiempo de ejecución?
a) En un applet
b) En un EJB
c) En un servlet

? ¿Qué es JPA?

// Preguntas de examen (ene-2026): enunciados reales; opciones y respuestas contrastadas con la normativa/fuentes

? Indique la respuesta correcta sobre JPA:
a) El lenguaje de consulta orientado a objetos de JPA es JPSQL.
b) JPA no permite definir relaciones uno a muchos entre entidades.
c) Una de sus ventajas es que no necesita utilizar un proveedor de JPA.
d) Normalmente, una entidad representa una tabla de la base de datos relacional y cada instancia de la entidad corresponde a una fila.
= d
> JPA es una especificación: necesita un proveedor (Hibernate, EclipseLink…). Su lenguaje de consulta es JPQL y soporta @OneToMany, @ManyToOne, @ManyToMany y @OneToOne.
@ JPA

? ¿Qué ORM podría utilizar, en función de la solución de backend escogida?
a) Spring Data en .NET e Hibernate en Java.
b) Entity Framework en Java y Hibernate en .NET.
c) Dapper en Java y JDBC en .NET.
d) Entity Framework en .NET e Hibernate en Java.
= d
> Entity Framework Core es el ORM de .NET; Hibernate (u otro proveedor JPA) en Java. Spring Data es de Java.
@ ORM

? En un entorno de desarrollo Java, ¿qué utilizaría para mapear elementos XML a clases?
a) JPA.
b) JNDI.
c) JMS.
d) JAXB (Jakarta XML Binding).
= d
> JAXB realiza el marshalling/unmarshalling entre XML y objetos Java mediante anotaciones o a partir de un esquema XSD.
@ Java · XML
