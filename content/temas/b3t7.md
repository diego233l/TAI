## La Web y sus fundamentos

- **World Wide Web**: sistema de documentos hipertexto enlazados accesible por internet, ideado por **Tim Berners-Lee en el CERN (1989-1991)**. Se apoya en tres pilares: **URL** (identificación), **HTTP** (transferencia) y **HTML** (formato). El **W3C** (1994) estandariza HTML, CSS, XML, DOM…; la **WHATWG** mantiene el «HTML Living Standard».
- **URL**: `esquema://usuario@host:puerto/ruta?consulta#fragmento`. **URI** es el identificador general; **URL** localiza; **URN** nombra. El fragmento (`#`) lo gestiona solo el navegador y no se envía al servidor.
- **Modelo de funcionamiento**: el navegador (cliente) solicita recursos por HTTP/HTTPS; el servidor web (Apache, Nginx, IIS) devuelve contenido estático o generado dinámicamente (PHP, Java, .NET, Python, Node.js). HTTP es un protocolo **sin estado**; el estado se mantiene con **cookies**, sesiones o tokens.
- **Aplicación web**: se ejecuta en servidor y se usa desde el navegador. **MPA** (multipágina, recarga completa) frente a **SPA** (una página que carga datos por AJAX); **SSR** (renderizado en servidor) frente a **CSR** (en cliente); **PWA** (aplicación web progresiva: *service workers*, *manifest*, instalable, uso sin conexión).

## HTML

- **HTML** (*HyperText Markup Language*) es un lenguaje de **marcado** (no de programación). Versiones: HTML 4.01, XHTML 1.0 (sintaxis XML), **HTML5** (W3C, 2014; hoy *Living Standard*).
- **Estructura básica**: `<!DOCTYPE html>`, `<html lang="es">`, `<head>` (`<meta charset="utf-8">`, `<title>`, `<link>`, `<script>`) y `<body>`.
- **Elementos semánticos HTML5**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<figure>`/`<figcaption>`. Mejoran la accesibilidad y el SEO.
- **Formularios**: `<form action method>`, `<input type="text|email|password|number|date|checkbox|radio|file|hidden">`, `<label for>`, `<select>`, `<textarea>`, `<button>`; atributos de validación `required`, `pattern`, `min`, `max`, `placeholder`. `GET` envía datos en la URL; `POST` en el cuerpo.
- **Otros elementos**: enlaces `<a href>`, imágenes `<img src alt>` (el atributo `alt` es **obligatorio para la accesibilidad**), tablas (`<table> <tr> <th> <td>`), listas (`<ul> <ol> <li>`), multimedia `<audio>`, `<video>`, `<canvas>` y `<svg>`.
- **APIs de HTML5**: *Web Storage* (`localStorage`, persistente; `sessionStorage`, por pestaña; ~5 MB), **IndexedDB**, **Geolocation**, **Web Workers**, **WebSocket**, **Service Workers**, Fetch, History, Drag & Drop.
- Atributos globales: `id` (único), `class`, `style`, `title`, `lang`, `data-*`, atributos **ARIA** (`role`, `aria-label`) para accesibilidad.

## CSS

- **CSS** (*Cascading Style Sheets*) separa **presentación** y contenido. Formas de aplicarlo: **en línea** (`style`), **interno** (`<style>`) y **externo** (`<link rel="stylesheet">`, recomendado).
- **Selectores**: elemento (`p`), clase (`.aviso`), identificador (`#menu`), descendiente (`div p`), hijo (`div > p`), atributo (`[type=text]`), pseudoclases (`:hover`, `:first-child`) y pseudoelementos (`::before`).
- **Cascada y especificidad**: gana la regla más específica (`style` en línea > `#id` > `.clase` > elemento); `!important` anula; a igual especificidad, la última declarada. Hay **herencia** de propiedades como `color` o `font`.
- **Modelo de caja**: de dentro hacia fuera: **contenido → padding → borde → margen**. `box-sizing: border-box` incluye padding y borde en el ancho.
- **Maquetación**: `display` (`block`, `inline`, `inline-block`, `none`, `flex`, `grid`), `position` (`static`, `relative`, `absolute`, `fixed`, `sticky`), **Flexbox** (unidimensional) y **Grid** (bidimensional).
- **Diseño adaptable (*responsive*)**: `<meta name="viewport" content="width=device-width, initial-scale=1">`, **media queries** (`@media (max-width: 600px)`), unidades relativas (`%`, `em`, `rem`, `vw`, `vh`) y enfoque ***mobile first***. Variables CSS (`--color`), preprocesadores (Sass, LESS) y bibliotecas (**Bootstrap**, Tailwind).

## JavaScript

- **JavaScript**: lenguaje de script interpretado (compilado JIT), de **tipado dinámico**, basado en **prototipos** y multiparadigma; estandarizado como **ECMAScript** (ECMA-262). **ES2015 (ES6)** introdujo `let`/`const`, funciones flecha, clases, módulos, plantillas literales y *promesas*. No tiene relación con Java más allá del nombre.
- **DOM** (*Document Object Model*): representación en **árbol de nodos** del documento que JavaScript manipula: `document.getElementById`, `querySelector`, `createElement`, `addEventListener`, `textContent` (seguro) frente a `innerHTML` (riesgo de XSS con datos no confiables).
- **Eventos**: `click`, `submit`, `load`, `input`, `keydown`…; propagación en **burbuja** y **captura**.
- **Asincronía**: *callbacks*, **Promesas** (`then/catch`), **`async/await`**; el motor es de un solo hilo con **bucle de eventos**. **AJAX**: peticiones asíncronas (`XMLHttpRequest`, **`fetch`**) sin recargar la página; intercambio habitual en **JSON** (`JSON.parse`, `JSON.stringify`).
- **Detalles del lenguaje**: `==` compara con conversión de tipos y `===` sin conversión (preferible); `typeof`; `null` y `undefined`; *closures*; `this`; alcance de `var` (función) frente a `let`/`const` (bloque).
- **Entorno de servidor**: **Node.js** (motor V8; gestor de paquetes **npm**), Express. **TypeScript** añade tipado estático. **WebAssembly** permite ejecutar código compilado en el navegador.
- **Frameworks y bibliotecas**: **Angular** (Google; framework completo con TypeScript), **React** (Meta; biblioteca de componentes, *virtual DOM*, JSX), **Vue**; jQuery (heredado).

## Desarrollo en el servidor

- **Lenguajes**: **PHP** (embebido en HTML, variables con `$`, superglobales `$_GET`, `$_POST`, `$_SESSION`, acceso a datos con **PDO**; frameworks Laravel y Symfony), **Java** (Servlets/JSP, Spring), **C#/ASP.NET Core**, **Python** (Django, Flask), **Ruby on Rails**, **Node.js**, Go.
- **Servidores web**: **Apache HTTP Server**, **Nginx** (también proxy inverso y balanceador), **IIS**, Tomcat (contenedor de servlets). PHP suele ejecutarse con **PHP-FPM** (FastCGI).
- **Cookies**: `Set-Cookie` con atributos **`Secure`** (solo HTTPS), **`HttpOnly`** (inaccesible a JavaScript, mitiga XSS), **`SameSite`** (mitiga CSRF) y `Max-Age`/`Expires`. Las **sesiones** guardan el identificador en una cookie y los datos en el servidor.
- **CMS**: **WordPress** (PHP), Drupal, Joomla, Liferay.
- **Cabeceras HTTP** habituales: `Content-Type`, `Accept`, `Host`, `User-Agent`, `Cookie`, `Set-Cookie`, `Location`, `Cache-Control`, `ETag`, `Authorization`.
- **Rendimiento**: minificación, compresión **gzip/Brotli**, **caché HTTP**, **CDN**, carga diferida (*lazy loading*), **HTTP/2**.

## XML y sus derivaciones

- **XML** (*eXtensible Markup Language*, W3C, 1998): metalenguaje de marcas para describir y **intercambiar datos estructurados**, legible por personas y máquinas. Las etiquetas las define el usuario.
- **Documento bien formado**: un único **elemento raíz**; etiquetas **cerradas y correctamente anidadas**; atributos con valor **entre comillas**; **distingue mayúsculas y minúsculas**; caracteres especiales escapados (`&lt; &gt; &amp; &quot; &apos;`). Prólogo opcional `<?xml version="1.0" encoding="UTF-8"?>`; secciones `CDATA`; comentarios `<!-- -->`.
- **Documento válido**: además de bien formado, cumple una **DTD** o un esquema **XSD** (*XML Schema*, escrito en XML, con **tipos de datos** y espacios de nombres; más potente que la DTD).
- **Espacios de nombres** (`xmlns:prefijo="URI"`) evitan colisiones de nombres.
- **Tecnologías asociadas**: **XPath** (selección de nodos: `/factura/linea`, `//precio`, `@id`, `[1]`), **XSLT** (transformación de XML a XML, HTML o texto), **XQuery** (consulta), **XSD**.
- **Procesamiento**: **DOM** (carga todo el árbol en memoria; acceso aleatorio; consume memoria) frente a **SAX** (basado en eventos, secuencial, bajo consumo, solo lectura) y **StAX** (extracción por demanda).
- **Derivaciones y lenguajes basados en XML**: **XHTML**, **SVG** (gráficos vectoriales), **MathML**, **RSS/Atom**, **SOAP**, **WSDL**, **KML**, **XBRL**, **XAdES** (firma), **ODF/OOXML** (documentos ofimáticos) y la factura electrónica **Facturae**. Alternativas más ligeras: **JSON** y **YAML**.

## Navegadores, seguridad y multiplataforma

- **Motores**: **Blink** (Chrome, Edge, Opera) con motor JS **V8**; **Gecko** (Firefox, SpiderMonkey); **WebKit** (Safari, JavaScriptCore).
- **Política del mismo origen (*same-origin policy*)**: un script solo accede a recursos del mismo origen (esquema + host + puerto). **CORS** (`Access-Control-Allow-Origin`) permite excepciones controladas. **CSP** (*Content-Security-Policy*) restringe los orígenes de scripts y mitiga el XSS. **HSTS** obliga a usar HTTPS.
- **Multiplataforma y multidispositivo**: diseño **responsive** y **adaptativo**, PWA, aplicaciones **híbridas** (Cordova/Ionic) y multiplataforma (**React Native**, **Flutter**) frente a **nativas**. Pruebas de compatibilidad entre navegadores y dispositivos; herramientas de desarrollo del navegador.

## Lenguajes de script

- **Script**: programa interpretado que automatiza tareas, normalmente sin compilación previa. Ejemplos: **Bash/Shell**, **PowerShell**, **Python**, **Perl**, **JavaScript**, VBScript, **PHP**.
- Se emplean en administración de sistemas, automatización, procesamiento de texto, pruebas, despliegue y desarrollo web (cliente: JavaScript; servidor: PHP, Node.js, Python).
