## Lenguajes de programación: conceptos y clasificación

- **Lenguaje de programación**: lenguaje formal (sintaxis + semántica) para expresar algoritmos que una máquina pueda ejecutar.
- **Generaciones**: **1GL** lenguaje máquina, **2GL** ensamblador, **3GL** lenguajes de alto nivel (C, Java, Pascal), **4GL** lenguajes de muy alto nivel (SQL, generadores de informes), **5GL** lenguajes basados en restricciones o lógica (Prolog).
- **Paradigmas**: **imperativo/procedural** (C, Pascal, COBOL), **estructurado**, **orientado a objetos** (Java, C#, C++), **funcional** (Haskell, Lisp, F#, Scala), **lógico** (Prolog), **declarativo** (SQL, HTML), **orientado a eventos** y **concurrente**. Muchos lenguajes son **multiparadigma** (Python, JavaScript, Scala).
- **Tipado**: **estático** (comprobado en compilación: Java, C, C#) o **dinámico** (en ejecución: Python, JavaScript, PHP); **fuerte** (no permite mezclar tipos sin conversión explícita: Python, Java) o **débil** (conversiones implícitas permisivas: JavaScript, C).
- **Traducción**:
  - **Compilador**: traduce todo el código fuente a código objeto/ejecutable antes de la ejecución (C, C++, Go, Rust).
  - **Intérprete**: traduce y ejecuta instrucción a instrucción (Python, PHP, JavaScript clásico).
  - **Híbrido**: Java compila a **bytecode** que ejecuta la **JVM** con compilación **JIT**; C# compila a **CIL** que ejecuta el **CLR**.
  - **Fases de un compilador**: análisis **léxico** (tokens), **sintáctico** (árbol sintáctico), **semántico**, generación de **código intermedio**, **optimización** y generación de **código final**. El **enlazador (*linker*)** une módulos objeto y bibliotecas; el **cargador (*loader*)** lo lleva a memoria.
- **Lenguajes de uso habitual**: **C** (compilado, punteros, memoria manual con `malloc/free`), **C++**, **Java** (JVM, «escribe una vez, ejecuta en cualquier sitio»), **C#**, **Python** (indentación significativa, tipado dinámico), **JavaScript/TypeScript** (TypeScript es un superconjunto tipado de JavaScript), **PHP**, **Go**, **Rust** (seguridad de memoria sin recolector), **Kotlin**, **COBOL** (sistemas administrativos), **PL/SQL**.

## Tipos de datos, variables y constantes

- **Variable**: espacio de memoria con nombre y tipo cuyo valor puede cambiar; **constante**: valor fijo (`const`, `final`). **Ámbito (*scope*)**: **global** o **local** (de bloque/función); **tiempo de vida**: mientras existe en memoria.
- **Tipos primitivos**: **entero**, **real (coma flotante)**, **carácter**, **lógico/booleano**. **Compuestos**: **cadena**, **array (vector/matriz)**, **registro (struct)**, enumerado, conjunto, tupla. **Punteros/referencias** guardan direcciones.
- **Tipos primitivos de Java**: `byte` (8 bits, −128…127), `short` (16), `int` (32 bits, −2³¹…2³¹−1), `long` (64), `float` (32), `double` (64), `char` (16, Unicode UTF-16), `boolean`.
- **Conversión de tipos**: **implícita** (ensanchamiento: int → double) o **explícita (*casting*)** `(int) 3.7` → 3 (truncamiento). Riesgo de **desbordamiento** (*overflow*) y pérdida de precisión.
- **Coma flotante**: `0.1 + 0.2 != 0.3` exactamente por la representación binaria; las comparaciones de reales se hacen con una tolerancia.
- **Cadenas**: inmutables en Java, C# y Python; en C son arrays de `char` terminados con `'\0'`.
- **Memoria**: **pila (*stack*)** para variables locales y llamadas; **montículo (*heap*)** para objetos dinámicos; **recolector de basura** (Java, C#, Python) o gestión manual (C/C++).

## Operadores y expresiones

| Tipo | Operadores | Notas |
|---|---|---|
| **Aritméticos** | `+ - * / %` | `/` entre enteros es **división entera** (`7/2 = 3`); `%` es el resto (`7 % 2 = 1`) |
| **Relacionales** | `== != < > <= >=` | Devuelven booleano; no confundir `=` (asignación) con `==` |
| **Lógicos** | `&& \|\| !` | Con **cortocircuito**: en `A && B` no se evalúa B si A es falso |
| **Bit a bit** | `& \| ^ ~ << >>` | `x << 1` multiplica por 2 |
| **Asignación** | `= += -= *= ++ --` | `i++` (postfijo: usa y luego incrementa) frente a `++i` (prefijo) |
| **Condicional** | `cond ? a : b` | Operador ternario |

- **Precedencia** (de mayor a menor, en lenguajes tipo C/Java): paréntesis, unarios (`! ++ --`), `* / %`, `+ -`, relacionales, igualdad, `&&`, `||`, asignación.
- **Truncamiento**: en Java y C, `-7 / 2 = -3` y `-7 % 3 = -1` (el resto toma el signo del dividendo); en Python, `-7 // 2 = -4` y `-7 % 3 = 2`.

## Estructuras de control

- **Programación estructurada** (teorema de **Böhm-Jacopini**): todo algoritmo puede expresarse con **secuencia, selección e iteración**, sin `GOTO` (Dijkstra).
- **Selección**: `if / else if / else`; `switch / case` (en C/Java hace falta `break` para no «caer» a los casos siguientes); operador ternario.
- **Iteración**:
  - `while (cond) { … }`: evalúa **antes**; puede no ejecutarse nunca.
  - `do { … } while (cond);`: evalúa **después**; se ejecuta **al menos una vez**.
  - `for (init; cond; paso) { … }`: número conocido de repeticiones; `for-each` recorre colecciones.
  - `break` sale del bucle; `continue` salta a la siguiente iteración.
- **Ejemplo de traza**: `s=0; for (i=1; i<=4; i++) s += i;` → `s = 10`. `i=10; while (i>0) i -= 3;` → termina con `i = -2`.

## Procedimientos, funciones y parámetros

- **Procedimiento** (*void*): realiza acciones, **no devuelve valor**. **Función**: **devuelve un valor** (`return`). Ambos son **subprogramas** (modularidad, reutilización, ocultación).
- **Parámetros formales** (en la definición) y **actuales o argumentos** (en la llamada).
- **Paso de parámetros**: **por valor** (se copia el valor; la modificación no afecta al original), **por referencia** (se pasa la dirección; la modificación sí afecta al original: `&` en C++, `ref` en C#), por resultado. **Java pasa siempre por valor** (para objetos, se copia la referencia).
- **Sobrecarga** (mismo nombre, distinta firma), parámetros por defecto, número variable de argumentos. **Función pura**: mismo resultado para los mismos argumentos y sin efectos secundarios. **Lambdas/closures** y funciones de orden superior (`map`, `filter`, `reduce`).
- **Recursividad**: subprograma que se llama a sí mismo; requiere **caso base** y avance hacia él; cada llamada ocupa un **marco de pila** (riesgo de *stack overflow*). Ejemplos:
  - `factorial(n) = n * factorial(n-1)`, con `factorial(0) = 1`.
  - **Fibonacci**: `fib(n) = fib(n-1) + fib(n-2)` (ingenuo: O(2ⁿ)).
  - **Torres de Hanoi**: n discos → **2ⁿ − 1** movimientos.
  - **Máximo común divisor (Euclides)**: `mcd(a, b) = mcd(b, a mod b)`; `mcd(a, 0) = a`.
  - Una recursión **de cola** puede convertirse en iterativa.

## Vectores (arrays) y registros

- **Array**: colección de elementos del **mismo tipo** con índice; en C, Java, C# y Python **el primer índice es 0**. Un array de *n* elementos tiene índices `0 … n−1`; salirse del rango provoca error (excepción en Java, comportamiento indefinido en C). **Matriz**: array bidimensional `m[i][j]` (filas × columnas).
- **Registro (*struct/record*)**: agrupa campos de **tipos distintos** bajo un nombre; los arrays de registros modelan tablas.
- **Algoritmos habituales sobre vectores**: recorrido, búsqueda secuencial/binaria, suma, máximo/mínimo, ordenación, inversión.

## Estructura de un programa y buenas prácticas

- Partes: **cabecera** (importaciones/`#include`, paquete), **declaraciones** (constantes, tipos, variables globales), **subprogramas** y **programa principal** (`main`).
  - **C**: `#include <stdio.h>` + `int main(void) { … return 0; }`.
  - **Java**: `package` + `import` + `class` + `public static void main(String[] args)`.
  - **Python**: sin llaves; el bloque se marca con la **indentación**.
- **Representación de algoritmos**: **pseudocódigo**, **diagramas de flujo** (ordinogramas) y diagramas **Nassi-Shneiderman**.
- **Convenciones**: `camelCase` (Java/JS), `PascalCase` (clases), `snake_case` (Python/C), constantes en `MAYÚSCULAS`.
- **Gestión de errores**: **excepciones** (`try / catch / finally`, `throw`), códigos de retorno. El bloque `finally` se ejecuta **siempre**.
- **Calidad**: comentarios útiles, funciones cortas y con una responsabilidad, nombres descriptivos, evitar variables globales, **depuración** (puntos de ruptura, trazas) y **pruebas**.
