## Plataforma Java

- **JVM** (máquina virtual), **JRE** (JVM + bibliotecas), **JDK** (JRE + compilador `javac` y herramientas). El código `.java` se compila a **bytecode** (`.class`), que ejecuta la JVM (con compilación **JIT**) en cualquier sistema operativo («write once, run anywhere»). Gestión de memoria con **recolector de basura**.
- **Ediciones**: **Java SE** (estándar), **Java EE / Jakarta EE** (empresarial), Java ME (dispositivos limitados). Versiones **LTS** habituales: 8, 11, 17, 21 y 25.
- Herramientas de construcción: **Maven** (`pom.xml`, repositorio central) y **Gradle**; pruebas con **JUnit**; registros con SLF4J/Log4j.

## Java EE / Jakarta EE

- **Java EE** (Sun/Oracle) es el conjunto de especificaciones para aplicaciones empresariales distribuidas, multicapa y transaccionales. Oracle lo cedió a la **Eclipse Foundation**, que lo renombró **Jakarta EE** (por marca registrada). **Jakarta EE 8** (2019) mantiene el espacio de nombres `javax.*`; desde **Jakarta EE 9** (2020) los paquetes pasan a **`jakarta.*`**. Después llegaron Jakarta EE 10 (2022; con perfil **Core**) y Jakarta EE 11 (2025). Perfiles: **Web Profile**, **Platform** y **Core Profile**.
- **Servidores de aplicaciones**: GlassFish, **WildFly/JBoss EAP**, Payara, Open Liberty, TomEE, WebLogic, WebSphere. **Tomcat** y **Jetty** son **contenedores web** (servlets/JSP), no servidores EE completos.
- **Modelo multicapa**: **cliente** (navegador) → **capa web** (Servlets, JSP, Faces) → **capa de negocio** (EJB, CDI) → **capa de integración/persistencia** (JPA, JDBC, JMS) → **sistemas de información empresariales** (BD, ERP). El **contenedor** (web, EJB) gestiona ciclo de vida, **inyección de dependencias**, **transacciones**, **seguridad**, concurrencia y recursos mediante anotaciones y descriptores (`web.xml`, `persistence.xml`).

### Tecnologías principales

| Tecnología | Función |
|---|---|
| **Servlet** | Clase Java (`HttpServlet`) que atiende peticiones HTTP; ciclo de vida `init()` → `service()` (`doGet`, `doPost`) → `destroy()`; el contenedor crea **una instancia** y usa **hilos** por petición; sesión con `HttpSession`; **filtros** y *listeners* |
| **JSP** | Páginas HTML con código Java/EL que **se compilan a servlets**; JSTL y EL (`${…}`) en lugar de *scriptlets* |
| **Jakarta Faces (JSF)** | Marco de **componentes** de interfaz del lado del servidor, con Facelets (XHTML) |
| **EJB** | Componentes de negocio gestionados por el contenedor: **Session** (*stateless*, *stateful*, *singleton*) y **Message-Driven Beans**; transacciones declarativas |
| **CDI** | Inyección de dependencias y contextos (`@Inject`, `@RequestScoped`, `@SessionScoped`, `@ApplicationScoped`) |
| **JPA (Jakarta Persistence)** | **ORM**: `@Entity`, `@Id`, `@GeneratedValue`, `@OneToMany`, `@ManyToOne`, `@ManyToMany`; `EntityManager` (`persist`, `merge`, `remove`, `find`); consultas **JPQL** y Criteria API; implementaciones **Hibernate** y **EclipseLink** |
| **JDBC** | API de acceso a BD relacionales: `DataSource`/`DriverManager`, `Connection`, `PreparedStatement`, `ResultSet`; *pool* de conexiones |
| **JTA** | Transacciones (incluidas distribuidas); `@Transactional` |
| **JMS** | Mensajería asíncrona: **colas (*queue*, punto a punto)** y **temas (*topic*, publicación/suscripción)** |
| **JAX-RS** | Servicios **REST** (`@Path`, `@GET`, `@POST`, `@Produces`) |
| **JAX-WS** | Servicios web **SOAP** |
| **Bean Validation** | Validación declarativa (`@NotNull`, `@Size`, `@Email`) |
| **JNDI** | Directorio de nombres para localizar recursos |
| **WebSocket**, JSON-P/JSON-B, JavaMail | Comunicación bidireccional, JSON, correo |

- **Spring / Spring Boot**: marco no EE de **inversión de control**, MVC, acceso a datos (Spring Data JPA) y seguridad (Spring Security); aplicaciones autocontenidas con servidor **Tomcat embebido**. **MicroProfile** adapta Jakarta EE a microservicios.

### Seguridad en Jakarta EE

- **Autenticación**: `BASIC`, `FORM`, `DIGEST`, `CLIENT-CERT` (certificado de cliente sobre TLS); **JAAS**; hoy se usan **OAuth 2.0 / OpenID Connect / JWT**.
- **Autorización por roles**: **declarativa** (`<security-constraint>` en `web.xml`, anotaciones `@RolesAllowed`, `@PermitAll`, `@DenyAll`) o **programática** (`isUserInRole`, `getUserPrincipal`).
- Comunicaciones por **TLS**; validación de entradas y *prepared statements* frente a inyección; protección frente a **XSS** y **CSRF**.

## Plataforma .NET

- **.NET Framework** (2002; solo Windows; última versión 4.8) → **.NET Core** (2016; multiplataforma y código abierto) → **.NET 5 y posteriores** (plataforma unificada llamada simplemente «.NET»). Las versiones pares son **LTS** (6, 8, 10).
- **Arquitectura**: **CLR** (*Common Language Runtime*; ejecución, JIT, recolector de basura, seguridad), **CIL/MSIL** (lenguaje intermedio), **CTS** (sistema común de tipos), **CLS** (especificación común de lenguajes) y **BCL** (biblioteca de clases base). Los programas se empaquetan en **ensamblados** (`.dll`/`.exe`) con metadatos. Lenguajes: **C#**, VB.NET, **F#**.
- **Aplicaciones web**: **ASP.NET Core** (multiplataforma, servidor **Kestrel**, *pipeline* de **middleware**, inyección de dependencias integrada, configuración `appsettings.json`), **MVC**, **Razor Pages**, **Web API** (REST), **Blazor** (interfaz web con C# en servidor o WebAssembly), **SignalR** (tiempo real). **IIS** como servidor en Windows.
- **Acceso a datos**: **ADO.NET** (`SqlConnection`, `SqlCommand`, `SqlDataReader`, `DataSet`) y **Entity Framework Core** (ORM: `DbContext`, `DbSet<T>`, migraciones, enfoques *Code First* y *Database First*) con **LINQ** (consultas integradas en el lenguaje).
- **Escritorio y móvil**: **Windows Forms**, **WPF** (interfaz con **XAML** y patrón **MVVM**), WinUI, **.NET MAUI** (aplicaciones multiplataforma, sucesor de Xamarin). **WCF** (servicios SOAP, heredado), gRPC y Web API.
- **Programación asíncrona**: `async`/`await`. Paquetes con **NuGet**; herramientas: Visual Studio, VS Code, CLI `dotnet`.
- **Seguridad**: **ASP.NET Core Identity**, autenticación por cookies, **JWT**, OAuth2/OpenID Connect y **Windows Authentication** (Kerberos/NTLM); autorización por **roles y políticas** (`[Authorize]`), protección de datos (*Data Protection API*), tokens **antiforgery**, HTTPS/HSTS.

| Concepto | Java / Jakarta EE | .NET |
|---|---|---|
| Entorno de ejecución | JVM | CLR |
| Código intermedio | Bytecode | CIL |
| ORM | JPA (Hibernate) | Entity Framework |
| Servidor/contenedor | Tomcat, WildFly… | Kestrel, IIS |
| Gestión de dependencias | Maven, Gradle | NuGet |
| Interfaz web servidor | JSF, JSP | Razor, Blazor |
| Servicios REST | JAX-RS | ASP.NET Web API |

## Desarrollo de interfaces

- **Java**: **AWT** (componentes nativos), **Swing** (ligeros, escritorio) y **JavaFX** (moderno, FXML y CSS). **Android** usa XML/Jetpack Compose.
- **.NET**: **Windows Forms** (basado en eventos), **WPF** (XAML, enlace de datos, MVVM), **MAUI**.
- **Web**: HTML, CSS y JavaScript con *frameworks* **Angular**, **React** y **Vue**; **diseño adaptable (*responsive*)**.
- **Conceptos comunes**: programación **dirigida por eventos** (eventos y *listeners/handlers*), **gestores de disposición (*layouts*)**, patrones **MVC/MVP/MVVM** que separan presentación y lógica, **accesibilidad** y **usabilidad**.
