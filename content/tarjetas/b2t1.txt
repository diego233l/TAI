Dato, información, conocimiento :: Dato: símbolo sin significado. Información: datos procesados con significado. Conocimiento: información interpretada y asimilada.
Sistema de información :: Datos, hardware, software, personas y procedimientos; funciones de entrada, proceso, almacenamiento y salida con retroalimentación.
Firmware :: Software grabado en memoria no volátil del dispositivo (BIOS/UEFI, controladoras).
Dígito hexadecimal / octal :: Hexadecimal = 4 bits; octal = 3 bits. FF₁₆ = 255.
Prefijos binarios (IEC) :: KiB = 2¹⁰ = 1024 B; MiB = 2²⁰; GiB = 2³⁰; TiB = 2⁴⁰. Los SI (kB, MB, GB) son potencias de 1000.
Byte :: 8 bits (octeto). Las velocidades de transmisión se miden en bit/s.
ASCII :: 7 bits, 128 caracteres. ASCII extendido: 8 bits (Latin-1, Windows-1252).
UTF-8 :: Longitud variable de 1 a 4 bytes; ASCII en 1 byte; ñ y vocales con tilde en 2 bytes; € en 3 bytes.
UTF-16 y UTF-32 :: UTF-16: 2 o 4 bytes (pares sustitutos). UTF-32: 4 bytes fijos.
Complemento a 2 :: Invertir bits y sumar 1. Rango −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1 (8 bits: −128 a 127). Un solo cero.
Signo-magnitud y complemento a 1 :: Tienen dos ceros (+0 y −0).
Desbordamiento en C2 :: 127 + 1 con 8 bits da 1000 0000 = −128 (overflow).
IEEE 754 simple precisión :: 32 bits: 1 signo + 8 exponente (sesgo 127) + 23 mantisa.
IEEE 754 doble precisión :: 64 bits: 1 signo + 11 exponente (sesgo 1023) + 52 mantisa.
BCD y código Gray :: BCD: 4 bits por dígito decimal. Gray: valores consecutivos difieren en un solo bit.
Puertas universales :: NAND y NOR.
Leyes de De Morgan :: ¬(A·B) = ¬A + ¬B; ¬(A+B) = ¬A · ¬B.
Semisumador :: Suma = A XOR B; acarreo = A AND B.
Bit de paridad :: Detecta un número impar de errores; no corrige.
Código de Hamming :: Corrige errores de 1 bit; con paridad global (SECDED) detecta errores dobles. Base de la memoria ECC.
Compresión con y sin pérdida :: Sin pérdida: ZIP, PNG, FLAC, Huffman, LZW. Con pérdida: JPEG, MP3, MPEG.
Shannon-Hartley y Nyquist :: C = B·log₂(1 + S/N) con ruido; C = 2B·log₂M sin ruido.
Modos de comunicación :: Símplex (un sentido), semidúplex (ambos sentidos alternados), dúplex (simultáneo).
Von Neumann frente a Harvard :: Von Neumann: memoria única para datos e instrucciones (cuello de botella). Harvard: memorias separadas (DSP, microcontroladores).
Registros de la CPU :: PC (siguiente instrucción), IR (instrucción actual), MAR (dirección), MDR/MBR (dato), SP (pila), flags.
Ciclo de instrucción :: Captación (fetch), decodificación, ejecución (y escritura de resultados).
Pipeline (segmentación) :: Solapa etapas de varias instrucciones; riesgos de datos, de control y estructurales; predicción de saltos.
RISC frente a CISC :: RISC (ARM, RISC-V): instrucciones simples de longitud fija, load/store. CISC (x86): instrucciones complejas y de longitud variable.
Taxonomía de Flynn :: SISD, SIMD (vectorial/GPU), MISD, MIMD (multiprocesadores).
Ley de Amdahl :: Aceleración = 1 / ((1 − p) + p/s).
Jerarquía de memoria :: Registros → caché L1/L2/L3 → RAM → SSD → HDD → cinta; localidad temporal y espacial.
DRAM y SRAM :: DRAM: condensadores, necesita refresco, memoria principal. SRAM: biestables, más rápida y cara, caché.
Políticas de escritura de la caché :: Write-through: escribe en caché y memoria. Write-back: solo en caché; vuelca al reemplazar (bloque sucio).
Memorias de solo lectura :: PROM (una vez), EPROM (borrado UV), EEPROM (borrado eléctrico), Flash (NOR/NAND).
Memoria direccionable :: 2ⁿ posiciones con bus de direcciones de n bits: 32 bits → 4 GiB.
MMU y TLB :: MMU traduce direcciones virtuales a físicas; la TLB cachea las traducciones.
DMA :: Transferencia entre periférico y memoria sin intervención continua de la CPU.
PCI Express :: Enlaces serie punto a punto con carriles (x1, x4, x8, x16). 3.0: 8 GT/s; 4.0: 16 GT/s; 5.0: 32 GT/s.
Factores de forma de placa base :: ATX 305×244 mm; microATX 244×244; Mini-ITX 170×170.
UEFI frente a BIOS :: UEFI: arranque GPT, discos > 2 TiB, Secure Boot, interfaz gráfica. Configuración en CMOS.
MBR frente a GPT :: MBR: 4 primarias, ≈ 2 TiB. GPT: 128 particiones por defecto, ≈ 8 ZiB.
DIMM y DDR :: DDR3 240 pines (1,5 V); DDR4 288 pines (1,2 V); DDR5 288 pines (1,1 V); incompatibles entre sí.
Velocidades USB :: 1.1: 12 Mbit/s; 2.0: 480 Mbit/s; 3.2 Gen 1: 5 Gbit/s; Gen 2: 10; Gen 2x2: 20; USB4: 40 Gbit/s.
SATA :: SATA I 1,5 Gbit/s; SATA II 3 Gbit/s; SATA III 6 Gbit/s (≈ 600 MB/s). NVMe va sobre PCIe (M.2).
Fuente de alimentación ATX :: Tensiones +3,3, +5 y +12 V; conector principal de 24 pines; certificación 80 PLUS.
Rack de 19 pulgadas :: 1U = 44,45 mm (1,75 in).
RAEE :: Directiva 2012/19/UE; en España, Real Decreto 110/2015.
Conversión decimal → binario :: Parte entera: divisiones entre 2 (restos de abajo arriba). Parte fraccionaria: multiplicaciones por 2. 13₁₀ = 1101₂.
Desplazamiento de bits :: Izquierda k posiciones = × 2ᵏ; derecha = ÷ 2ᵏ (aritmético conserva el signo).
XOR :: A XOR A = 0; invierte bits donde la máscara vale 1.
Modos de direccionamiento :: Inmediato, directo, indirecto, de registro, indexado y relativo.
Compilador, intérprete y ensamblador :: Compilador: traduce todo el programa a código objeto. Intérprete: traduce y ejecuta línea a línea. Ensamblador: traduce el lenguaje ensamblador.
Generaciones de ordenadores :: 1.ª válvulas; 2.ª transistores; 3.ª circuitos integrados; 4.ª microprocesadores; 5.ª paralelismo e IA.
VT-x y AMD-V :: Extensiones de virtualización por hardware de Intel y AMD.
Medidas de almacenamiento :: Latencia, throughput (MB/s) e IOPS.
