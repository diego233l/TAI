Se dispone del siguiente programa en Java (compila y se ejecuta sin errores):

```java
public class Prueba {
    static int mcd(int a, int b) { return b == 0 ? a : mcd(b, a % b); }
    static int f(int n) { return n <= 1 ? n : f(n - 1) + f(n - 2); }
    static void incrementa(int x, int[] v) { x++; v[0]++; }

    public static void main(String[] args) {
        int[] a = {5, 3, 8, 1};
        int s = 0;
        for (int i = 0; i < a.length; i++) {
            if (a[i] % 2 == 1) s += a[i];
        }
        System.out.println("s=" + s);                        // (1)
        System.out.println(mcd(84, 36));                     // (2)
        System.out.println(f(7));                            // (3)
        int x = 10; int[] v = {10};
        incrementa(x, v);
        System.out.println(x + "," + v[0]);                  // (4)
        int i = 0, c = 0;
        do { c += i; i += 3; } while (i < 10);
        System.out.println(c + " " + i);                     // (5)
        int p = 7, q = 2;
        System.out.println(p / q + " " + p % q + " " + (double) p / q);   // (6)
        System.out.println(p > 5 || p / (q - 2) > 0);        // (7)
        for (int j = 0; j < a.length - 1; j++) {
            if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
        }
        System.out.println(java.util.Arrays.toString(a));    // (8)
        System.out.println("1" + 2 + 3);                     // (9)
        System.out.println(1 + 2 + "3");                     // (10)
        int k = 5;
        int r = k++ + ++k;
        System.out.println(r + " " + k);                     // (11)
    }
}
```

Las líneas numeradas como comentario indican cada impresión. Los valores de `a` en (8) son los del array **tal y como está en ese punto** (no se ha modificado antes).

c) s=8

= a
> Se suman los elementos impares del array: 5 + 3 + 1 = 9.
